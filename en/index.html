Subagents

Master Claude Code specialists—from the first .md to the multi-agent fleet. Learn when to delegate, how to create agents that trigger automatically, and orchestrate an entire team by choosing the right model for each task.

Start with Track 1 → View the 4 tracks

What you’ll learn

From “I've never created a subagent” to “I build and orchestrate my own system of specialists.” Seven concrete outcomes:

1

Explain the difference between agent, subagent, and skill and choose the right primitive.

2

Articulate the real reason for the subagents (context protection) and apply the “deciding question.”

3

Create a custom subagent from scratch: frontmatter + body, with a description that triggers automatically.

4

Restrict tools (read-only) and choose between project × global.

5

Match model with task (Haiku/Sonnet/Opus) and build the "smart manager + cheap workers" pattern.

6

Orchestrate chains, impartial reviewer and dynamic workflows—with a sense of the cost.

7

Take the concept to other environments/models (Codex, cross-runtime) and build your own library of specialists safely.
